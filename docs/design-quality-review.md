# Design quality and curation review

This iteration keeps the original eight routes and 28 numbered artifacts per board. A retained artifact has a specific role; it is not counted as a new exploration simply because it exists. Material studies are original vector illustrations, not claims of scanned physical samples. Photography remains the existing local collection.

## Three distinct directions

- **Calm:** reading-oriented planning, restrained action hierarchy, clear chronological grouping and quiet supporting surfaces.
- **Arcade:** checkpoints earn XP, the final reward unlocks a bonus experience, and reset returns to the starting state.
- **Editorial:** a numbered contents index opens a reading column with byline, chapters, progress and a session bookmark.

## Calm application contract

The final site retains the 1280px container and identity. Display type is 44–76px on desktop and 42px for the mobile trip heading; section headings are 30–42px and card headings 25–32px. Reading descriptions use at least 16px; explanatory metadata and controls use 14px; brief overlines may use 12px. Brand microtype is decorative identity, not instructional copy. The design-system page documents these responsive variants.

Interactive borders use #697161. Decorative separators may use #D6D9CC. Cards use 0 4px 16px rgba(41,55,47,.03); featured photographs may use the stronger 0 8px 24px rgba(41,55,47,.08) treatment. Destructive text actions use terracotta without acquiring primary-button weight. Major groups follow the four-pixel spacing scale, including 20px and 28px steps; compact icon and label alignment may use 6px or 10px. pill shapes remain reserved for compact categories and metadata.

## State semantics

Selection indicates a current choice (accent and explicit selected/pressed semantics); success indicates a saved or earned result. The six-state action atlas uses a filter chip for selection rather than an unexplained selected action button. Live switches expose on/off, disabled, hover, press and keyboard focus. Removal replaces the destination card with a reversible empty state; restoration keeps its original data and returns focus to its action. Select and textarea error specimens can be corrected. A local loading simulation reserves content space, disables its pending action and announces completion without making a network request.

## Verification and limits

The design-quality browser suite captures every numbered artifact at 1440px and 390px, every system section, loading examples and all eight pages; it checks WCAG A/AA with axe, keyboard focus, states and horizontal overflow. Existing planner regressions cover trip/activity edits, date adjustments, money precision, budgets, checklist, dialog behavior and refresh reset. Screenshots are saved outside the repository.

These are frontend specimens, not live bookings, admissions or notifications. All interaction state resets on refresh. Automated accessibility checks supplement visual and keyboard review; they do not certify every screen-reader/browser combination or determine a course grade.
